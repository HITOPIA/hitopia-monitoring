Taruh referensi UI & design system khusus proyek ini di sini — mis. ekspor dari
Claude Design, screenshot acuan, token, atau spesifikasi komponen.

  dan mematuhinya (design system, token, gaya).
- Jika KOSONG → UI Agent mengalir sesuai kebutuhan (perilaku default).
- Prioritas: design/ proyek ini menimpa design-system/ (root, house style).
